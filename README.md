# Skill-lab-project
Nikhil.K 1CD25CS136 

Project idea:-
Intelligent Cloud Infrastructure Monitoring

Problem statement:-
Cloud engineers struggle to monitor large-scale cloud infrastructure, identify incidents quickly, and understand the root cause of failures. 
It provides a centralized dashboard that monitors cloud resources, detects anomalies, summarizes incidents, and recommends corrective actions using AI.

Features required:-
A. Real-time infrastructure monitoring- The dashboard gives engineers a single view of their infrastructure.
B. Intelligent anomaly detection-Instead of simply showing graphs, the system identifies unusual behavior.
